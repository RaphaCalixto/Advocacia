# Valença & Associados | Advocacia Estratégica & Soluções Complexas

Website institucional de alto padrão para advocacia boutique e consultoria jurídica de elite, focado em Direito Societário (M&A), Planejamento Patrimonial Sucessório (Family Office), Defesa Tributária no CARF e Contencioso perante os Tribunais Superiores (STF/STJ).

Desenvolvido com uma paleta de cores nobre e distinta (**Vinho Imperial, Ouro Queimado, Taupe e Alabastro**), cards com 4 geometrias exclusivas, animações de alta performance com **GSAP** e **Framer Motion**, e tipografia clássica editorial.

---

## 🎨 Paleta de Cores Institucional

- **Vinho Nobre / Burgundy** (`#491A36`): Base atmosférica, degradês noturnos profundos e glassmorphism refinado.
- **Ouro Queimado / Champanhe Antigo** (`#AD9273`): Realces metálicos, linhas finas de lapidação, botões com efeito glow e monograma OAB.
- **Taupe Acinzentado** (`#C1B7AF`): Textos analíticos, descritivos de precedentes e linhas divisórias em mármore.
- **Alabastro / Marfim** (`#E9E8E6`): Títulos de autoridade, números estatísticos e alta legibilidade.

---

## 🏛️ Geometrias Diferenciadas de Cards (Anti-"AI Slop")

1. **Card Chanfrado / Lapidado (Octogonal)**: Lapidação societária de alta precisão (M&A, Governança, Agronegócio).
2. **Card em Arco Romano**: Solidez e proteção geracional contínua (Holding Familiar & Sucessão).
3. **Card Assimétrico de Corte Diagonal**: Ruptura de passivos e defesa ágil (Direito Tributário & CARF).
4. **Card 3D Tilt Interativo**: Física realista e reflexo luminoso com o movimento do mouse (Tribunais Superiores STF/STJ).

## ⚡ Tecnologias e Bibliotecas

- **React 19** + **TypeScript**
- **Vite** (Build ultrarrápido e Hot Module Replacement)
- **Tailwind CSS** (Design system customizado com tokens exclusivos)
- **GSAP (GreenSock Animation Platform)** + **ScrollTrigger** via `@gsap/react`
- **Framer Motion** (Molas táteis, perspectiva 3D e modais com lightbox)
- **Lucide Icons**
- **Canvas Confetti** (Feedback interativo de celebração na triagem)

## 🛠️ Como Executar Localmente

```bash
# 1. Clonar o repositório
git clone https://github.com/RaphaCalixto/Advocacia.git
cd Advocacia

# 2. Instalar as dependências
npm install

# 3. Iniciar o servidor de desenvolvimento
npm run dev

# 4. Gerar o build otimizado para produção
npm run build
```
